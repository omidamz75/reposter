# معماری پروژه

## ساختار کلی پروژه
```
reposter/
├── core/                   # هسته اصلی
│   ├── database.py        # مدیریت دیتابیس
│   ├── scheduler.py       # مدیریت زمان‌بندی
│   ├── event_handler.py   # معماری Event-Driven
│   └── api.py            # API وبسایت
│
├── modules/               # ماژول‌های مستقل
│   ├── ads/             # مدیریت تبلیغات
│   ├── users/           # مدیریت کاربران
│   ├── channels/        # مدیریت کانال‌ها
│   ├── scheduler/       # زمان‌بندی پیشرفته
│   ├── payments/        # مدیریت پرداخت
│   ├── affiliate/       # همکاری در فروش
│   ├── notifications/   # نوتیفیکیشن
│   └── pwa/            # اتصال به وب
│
└── tests/               # تست‌های سیستم
```

## قابلیت‌های کلیدی
1. مدیریت تبلیغات
   - ذخیره و ویرایش بنرها
   - زمان‌بندی پیشرفته
   - بهینه‌سازی کیفیت
   
2. مدیریت کانال‌ها
   - افزودن و حذف کانال
   - تأیید مالکیت
   - گزارش‌گیری

3. سیستم پرداخت
   - اشتراک ماهانه
   - قیمت‌گذاری پلکانی
   - همکاری در فروش

4. امکانات پیشرفته
   - نوتیفیکیشن داخلی
   - داشبورد وب
   - PWA برای موبایل
   - بکاپ خودکار

## معماری فنی
- Event-Driven Architecture
- ماژولار و مستقل
- لاگینگ مرکزی
- دیتابیس یکپارچه
